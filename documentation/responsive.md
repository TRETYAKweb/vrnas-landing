# Адаптив

**Дата:** 2026-10-16 · **Где:** `@media` в конце `style.css`

## Что сделали
| Брейкпоинт | Что меняется |
|---|---|
| ≤ 1280px | навигация центрируется, gap 40px |
| ≤ 1080px | hero в одну колонку (фото под текстом), карточки друг под другом |
| ≤ 860px | навигация скрыта, H1 44px, блок клиентов и видео переносится |

## Почему
В макете есть только десктоп, поэтому мобильную версию додумываем сами. В новых секциях используем те же три брейкпоинта.
