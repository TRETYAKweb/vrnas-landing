# Как собирать секцию из Figma

Инструкция для каждой новой секции. Собрана по опыту секции 1 (Header + Hero).

## Что сделали
Порядок работы:
1. `get_metadata` по `7:21` (Homepage). Найти ноды секции, их ID есть в таблице прогресса в `CLAUDE.md`.
2. `get_design_context` по каждой видимой ноде, все вызовы одним пакетом. Код из ответа (React + Tailwind) — только справочник по размерам, отступам, цветам и шрифтам.
3. Скачать ассеты в `assets/` через `curl` (подробности в [figma-assets.md](figma-assets.md)).
4. Сверстать: разметку в `index.html`, стили в отдельный блок в `css/style.css`, адаптив в общие `@media` в конце файла.
5. Проверить в браузере (превью `site`) на 1440, 2000 и 375px и сравнить со скриншотом из `get_design_context`.
6. Поправить расхождения, показать результат пользователю.
7. Когда пользователь принял секцию, он запускает `/update-docs`: обновляется `documentation/` и статус в `CLAUDE.md`.

## Почему
Одна секция за раз: проверили на компе и телефоне, поправили, перешли дальше. Если просить весь сайт сразу, мелкие промахи разъезжаются по всей странице и править их придётся везде.

## Ошибки
- Позиции из `get_metadata` для повёрнутых слоёв и clip-групп бывают смещены. Если элемент встал не туда, сверяемся со скриншотом и не верим координатам слепо.
