# Стек: чистый HTML + CSS

**Дата:** 2026-10-16 · **Где:** `index.html`, `css/style.css`

## Что сделали
Без фреймворков и сборщика. Шрифт Chakra Petch подключается с Google Fonts. Цвета и шрифты из Figma вынесены в CSS-переменные в `:root`:

| Токен | Значение |
|---|---|
| `--black-100` | `#18181B` (фон страницы) |
| `--black-80` | `#252532` (карточки) |
| `--video-bg` | `#21232E` |
| `--grey-1` / `--grey-2` | `#B0B0B2` / `#D1D1D1` |
| `--blue` → `--pink` | `#0CBAF1` → `#E95CE9` (градиент) |

Классы именуем по БЭМ: `block__element--modifier`.

## Почему
Это лендинг без логики и состояния, поэтому React, сборщик и Tailwind здесь лишние. Figma MCP отдаёт код на React + Tailwind, но мы переводим его в обычный CSS.
