# Ассеты из Figma: скачивание и чистка SVG

**Дата:** 2026-10-16 · **Где:** `assets/icons`, `assets/images`

## Что сделали
- Иконки берём в SVG, фото в PNG, всё скачиваем через `curl` в `assets/`.
- Иконки и фото берём по URL из `get_design_context`. Иконки, сложенные из масок, и декор берём через `download_assets` с `defaultFormat: svg`.
- Из каждого SVG после `download_assets` удаляем:
  - `<rect ... fill="#4A4A58"/>` — серую подложку превью;
  - `<rect width="1440" height="9899" ... fill="#18181B"/>` — фон всего Homepage;
  - `clip-path="url(#clip0_0_1)"` с `<g id="Homepage">` — обрезку по фрейму 1440.
- После чистки расширяем `viewBox` до реальных границ графики. Примеры:
  - `waves.svg`: `0 0 1120 405`;
  - `grid.svg`: `-1585 0 2682 721`.

## Почему
Ссылки Figma MCP временные (около 7 дней), поэтому ассеты должны лежать в проекте. А `download_assets` экспортирует ноду вместе с фоном и обрезкой родительского фрейма.

## Ошибки
- Иконки карточек сначала пришли на сером квадрате `#4A4A58`.
- Волны и сетку сначала взяли PNG-скриншотами нод. У них непрозрачный фон и жёсткая обрезка по 1440, поэтому на широком экране были видны края. Исправили переходом на SVG.
- Для волн нужно брать всю группу `7:2047`, а не clip-group `7:2044` (736×353): она обрезана.
- **Вывод:** после экспорта всегда проверять SVG через `grep "<rect\|clip-path"`. Скриншоты нод не использовать как ассеты для полупрозрачного декора.
