# Раскладка: grid/flex вместо absolute из Figma

**Дата:** 2026-10-16 · **Где:** header, hero, `.features`

## Что сделали
Абсолютные координаты из `get_design_context` пересчитываем в отступы:
- `.container`: 1200px + 16px боковые отступы. В макете это x = 120…1320.
- Header: flex, высота 114px, gap навигации 64px. Кнопка «Contact us» прижата вправо через `margin-left: auto`.
- Hero: grid `1fr 526px`. Отступы считали как разницу `y` соседних нод (например, 201 − 114 = 87px сверху).
- Карточка преимуществ: grid из 3 колонок, gap 51px, padding `42px 64px 53px`.
- Градиентная рамка у кнопки сделана двумя фонами (`padding-box` + `border-box`), а не `border-image`.

`position: absolute` остался только у декора, штриха под «32k+» и кнопки Play на превью видео.

## Почему
Absolute-вёрстка из Figma правильно выглядит только на 1440px и не адаптируется. С `border-image` нельзя сделать скругления и плавные ховер-эффекты.
